# 前端 / 小程序：只打网关

管理端 Vue、微信小程序、H5 **不要**再分别配置 8081、8082……  
统一 API 根地址：

```text
http://<网关主机>:8080
```

若使用 Nginx（`deploy/nginx`），根地址改为 `http://<Nginx主机>`（默认 80），由 Nginx 反代到网关。

## 必须改的配置（按你使用的前端仓库）

| 端 | 常见位置 | 改成 |
| -- | -------- | ---- |
| 管理端 Vue | `.env.development` / `vue.config.js` 的 `proxy` / `baseUrl` | `http://localhost:8080` |
| 小程序 | `app.js` / 封装 request 的 `baseURL`；微信公众平台「request 合法域名」 | 网关或 Nginx 域名 |
| WebSocket 来单提醒 | 管理端 WS 地址 | `ws://localhost:8080/ws/{sid}` |

Token 头名保持不变（与网关 `AuthGlobalFilter` 一致）：

- 管理端：`token`
- 用户端：`authentication`

## 不要做

- 不要把上传接口指到 `sky-file:8086`，应走网关 `/admin/common/upload`
- 不要把支付指到 `sky-pay:8085`，应走网关 `/pay/**`（若前端有独立支付路径）
- 不要在 Nginx 里按业务拆多上游，除非你很清楚路由，否则一律 `proxy_pass` 到网关

Compose 示例：

- 网关在 IDE：`docker compose --profile nginx up -d nginx`（`nginx.host.conf`）
- 网关也在容器：`--profile apps`（`nginx.conf`）
