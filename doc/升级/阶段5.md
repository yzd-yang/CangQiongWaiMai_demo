1. **Sentinel**：热点限流、Feign 降级；依赖挂了不拖垮整条链
2. **Seata（方案 A）**：`sky-pay` 记支付流水 + `sky-trade` 改订单状态，用 `@GlobalTransactional` 演示跨服务回滚

```text
Sentinel 练习链：
  菜品列表 / 下单 → 限流
  trade Feign → product 挂掉 → Fallback

Seata 方案 A：
  C 端支付 → trade PayClient
       → sky-pay  @GlobalTransactional
            ├─ ① 写 sky_pay.payment
            └─ ② Feign OrderClient.paySuccess → sky-trade 改 orders
  ② 故意失败 → ① 必须回滚
```

**本阶段不做**：Docker 一键编排全家桶（阶段 6）、方案 B 库存（可选加分）。

推荐顺序（**做完一块验收一块**）：

```text
Sentinel Dashboard
  → 业务服务接 Sentinel + 限流
  → Feign + Fallback / 熔断
  → 部署 Seata TC + undo_log
  → sky-pay 落库 payment
  → @GlobalTransactional 方案 A
  → 故意失败看回滚
```

## 9. 微服务接入 Seata



### 9.1 依赖（pay + trade）

  <groupId>com.alibaba.cloud</groupId>

### 9.2 配置要点（两边对齐）

示意（地址、group 换成你的）：

```yaml
seata:
  enabled: true
  application-id: ${spring.application.name}
  tx-service-group: default_tx_group
  service:
    vgroup-mapping:
      default_tx_group: default
  registry:
    type: nacos
    nacos:
      server-addr: 192.168.6.128:8848
      application: seata-server
      group: SEATA_GROUP
  config:
    type: nacos
    nacos:
      server-addr: 192.168.6.128:8848
      group: SEATA_GROUP
```

数据源：AT 需要被 Seata 代理。新版 starter 常自动代理；若本地事务进不了全局事务，查是否关闭了 `enable-auto-data-source-proxy`。

Feign：确保 XID 能传到下游（Seata 对 OpenFeign 一般有拦截器；若分支 2 没出现，优先查传 XID / group 是否一致）。

## 15. 常见坑


| 现象                         | 排查                                           |
| -------------------------- | -------------------------------------------- |
| Sentinel 控制台无应用            | 没访问过接口；dashboard 地址错；transport.port 冲突       |
| 限流不生效                      | 资源名与规则不一致（上下文路径、网关剥路径）                       |
| Feign 不降级                  | 未 `sentinel.enabled`；未配 fallback；超时太长先卡住     |
| Seata 连不上 TC               | 版本、registry、nacos 地址、group                   |
| `@GlobalTransactional` 不回滚 | 异常被 catch 吃掉；undo_log 缺失；数据源未代理；Feign 未传 XID |
| 只回滚了一边                     | 两边 tx-service-group / vgroupMapping 不一致      |
| pay 无库连接                   | 本阶段必须给 pay 配自己的库，禁止连 trade 库                 |
| WS 与回滚不一致                  | 演示时先关推送                                      |
