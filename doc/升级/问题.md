## 1. OpenFeign 报 `dependencies.dependency.version` is missing

### 现象

对工程执行 `mvn clean`（或 IDEA Maven 刷新）时报错，类似：

```text
'dependencies.dependency.version' for org.springframework.cloud:spring-cloud-starter-openfeign:jar is missing.
The project com.sky:sky-api:0.0.1-SNAPSHOT (...\sky-api\pom.xml) has 1 error
```

### 原因（白话）

- `sky-api` 里加了 `spring-cloud-starter-openfeign`，**没写 `<version>`**（指望 BOM 自动管版本）。
- OpenFeign 的版本写在根工程 `sky-take-out` 的 `dependencyManagement` 里（`spring-cloud-dependencies` BOM）。
- 当时 `sky-api` 的 `<parent>` 却是 **Spring Boot 官方 parent**，不是 `sky-take-out`。
- Boot parent **不管** Spring Cloud 依赖版本 → Maven 找不到版本 → 直接失败。

一句话：**要了零件没写型号，又没挂到项目的“版本总表”上。**

### 正确做法

1. 根 `pom.xml` 的 `<modules>` 登记该模块，例如：

```xml
<module>sky-api</module>
```

2. 子模块 `pom.xml` 的 parent 改成项目父工程：

```xml
<parent>
    <groupId>com.sky</groupId>
    <artifactId>sky-take-out</artifactId>
    <version>1.0-SNAPSHOT</version>
</parent>
```

3. OpenFeign / Nacos 等 Cloud 依赖**继续不写 version**，由根 BOM 统一管理。
4. 在**仓库根目录**执行 `mvn clean` / `mvn install`。

### 不推荐的临时办法

在依赖上写死 `<version>`，或在子模块再单独 `import` 一份 Cloud BOM——容易和根工程版本打架。

### 适用范围

下列模块**一律**认 `sky-take-out` 为 parent，并写入根 `<modules>`：

| 模块 | 说明 |
|------|------|
| `sky-api` | Feign 契约 |
| `sky-user` / `sky-product` / `sky-trade` | 业务域 |
| `sky-report` / `sky-pay` / `sky-file` | 报表 / 支付 / 文件 |
| `sky-gateway` | 网关（阶段 4） |

用 IDEA「新建 Spring Boot 工程」时，默认 parent 往往是官方 Boot——**建完后务必改成 `sky-take-out`**。

## 2. 误依赖 `sky-server` → bean 名冲突

### 现象

```text
ConflictingBeanDefinitionException: ... categoryServiceImpl
  com.sky.service.impl.CategoryServiceImpl
  conflicts with ... com.sky.service.Impl.CategoryServiceImpl
```

### 原因

业务服务（如 `sky-product`）缺 `AutoFill` 等类时，IDE 提示「添加对 sky-server 的依赖」。依赖后 `@SpringBootApplication` 扫描 `com.sky.**`，把单体里同名 `*ServiceImpl` 也扫进来，与本服务拷贝的实现冲突。

### 正确做法

- **不要**依赖 `sky-server`
- 缺什么就从单体 **拷贝到本服务**（或抽到 `sky-common`）：如 `AutoFill`、`AutoFillAspect`、拦截器
- 包名统一小写 `impl`，避免 Windows 下 `Impl` / `impl` 混用

## 3. 配置占位符未解析

### 现象

```text
ClassNotFoundException: ${sky.datasource.driver-class-name}
```

### 原因

`application.yaml` 里 `spring.profiles.active: dev`（或 `local`），但真正写 `sky.datasource.*` 的文件名对不上（例如只有 `application-local.yaml`）。

### 正确做法

- `active: local` ↔ `application-local.yaml`
- 或 `active: dev` ↔ `application-dev.yaml`
- `mybatis.type-aliases-package: com.sky.entity`（实体在 `sky-pojo`，不要写成 `com.sky.xxx.entity`）

## 4. IDE 误把公共包改成 `com.sky.trade.*`

### 现象

编译报 `程序包 com.sky.dto 不存在`；`sky-pojo` / `sky-common` 下出现 `com.sky.trade.dto`、`com.sky.trade.result` 等。

### 原因

抽 `sky-trade` 时用了「移动包 / 重构」，把整个 `com.sky` 改成了 `com.sky.trade`，公共模块被一起改坏。

### 正确做法

- `sky-pojo`、`sky-common` **永远**是 `com.sky.dto` / `com.sky.entity` / `com.sky.result` …
- 只迁本服务的 Controller / Service / Mapper；**禁止**对公共模块做全局改包名
- 若已误改：全文 `com.sky.trade.` → `com.sky.`，并把目录迁回 `com/sky/`

## 5. 同一服务名多个 `@FeignClient` 启动失败

### 现象

```text
BeanDefinitionOverrideException: sky-user.FeignClientSpecification
... already been defined and overriding is disabled
```

### 原因

例如同时存在：

```java
@FeignClient(name = "sky-user") interface AddressBookClient { ... }
@FeignClient(name = "sky-user") interface UserClient { ... }
```

Spring 用服务名注册 `FeignClientSpecification`，重名即冲突。

### 正确做法（推荐）

合并为 **一个** Client：

```java
@FeignClient(name = "sky-user")
public interface UserClient {
    @GetMapping("/inner/addressBook/{id}")
    AddressBook getById(@PathVariable Long id);
    // 其它 user 域内部接口...
}
```

或拆多个接口时加不同 `contextId`，`name` 仍指向同一服务。

**不要**用 `spring.main.allow-bean-definition-overriding=true` 掩盖。

本仓库现状：地址查询已合并进 `UserClient`，无独立 `AddressBookClient`。

## 6. 其它速查

| 现象 | 处理 |
|------|------|
| Feign 401 | Inner 走 `/inner/**`，拦截器 `excludePathPatterns("/inner/**")` |
| `@EnableFeignClients` 无效 | `basePackages = "com.sky.skyapi"`（与代码包一致） |
| file 上传仍指向 8080 | 配 `sky.file.upload-path` / `access-prefix` |
| pay 里出现 `orderMapper` / WebSocket | 删掉；改库与 WS 留在 trade，pay 只调 `OrderClient` |
| 误拷 `WebSocketConfiguration` 到 product | 删掉；WS 属于 trade |
| MapperScan 扫不到 | 包名与 `@MapperScan` 一致（user 曾用 `com.sky.skyuser.mapper`） |
