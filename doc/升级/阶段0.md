## 1. MySQL Docker 部署示例

```bash
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e TZ=Asia/Shanghai \
  -e MYSQL_ROOT_PASSWORD=123 \
  -v /root/mysql/data:/var/lib/mysql \
  -v /root/mysql/conf:/etc/mysql/conf.d \
  -v /root/mysql/init:/docker-entrypoint-initdb.d \
  --network hm-net \
  mysql
```

导入脚本：项目根目录 `sky.sql`。  
应用侧修改 `application-dev.yml` 中 `sky.datasource.host/port/username/password`。

本机连通性自检（PowerShell）：

```powershell
Test-NetConnection <MySQL主机IP> -Port 3306
```



## 2. Redis Docker 部署示例

```bash
sudo docker run -d \
  --name redis \
  -p 6379:6379 \
  --restart unless-stopped \
  redis:7.2 \
  redis-server --appendonly yes
```

应用侧：`sky.redis.host/port`；Spring 配置前缀为 `spring.data.redis`。
