## 目标

把单体 `sky-server` **按域迁到独立服务**，注册 Nacos，跨域改 Feign。

```PowerShell
docker run -d \
--name nacos \
--env-file ./nacos/custom.env \
-p 8848:8848 \
-p 9848:9848 \
-p 9849:9849 \
--restart=always \
nacos/nacos-server:v2.1.0-slim
```

**本阶段不上网关**：用各服务自己的端口 + Knife4j 联调。JWT 先留在各服务拦截器（或 Feign 联调用 `/inner/`**）。

推荐顺序（由易到难，**迁完一个验收一个**）：

```text
BOM + 空骨架 + Nacos
  → sky-product
  → sky-user
  → sky-trade（Feign 调 product / user）
  → sky-file / sky-pay
  → sky-report
  → 归档 sky-server
```

## 4. `sky-api` 约定（对齐笔记 `hm-api`）

**本仓库实际包名：** `com.sky.skyapi.client`（笔记里常写 `com.sky.api`，以代码为准）。

**只放：**

- `@FeignClient(name = "sky-xxx")` 接口
- 跨服务用的精简 DTO（初期可复用 `sky-pojo`）
- 可选：`DefaultFeignConfig`（日志级别）

**不要放：** Mapper、Service 实现、数据源、Controller。

Fallback 可阶段 5 再补。

启动类（**调用方** trade / pay / report）：

```java
@EnableFeignClients(basePackages = "com.sky.skyapi")
```

被调用方：提供与 Feign 路径一致的 Controller。建议单独一组 **内部接口**，避开 JWT：

```text
/inner/dish/{id}、/inner/setmeal/{id}、/inner/dish|setmeal/count
/inner/addressBook/{id}、/inner/user/count
/inner/order/paySuccess/{orderNumber}、/inner/order/count|sumAmount|top10
```

在该服务 `WebMvcConfiguration` 里 `excludePathPatterns("/inner/**")`。

**同一服务名只注册一个 FeignClient**：例如地址与用户统计都挂在 `UserClient(name = "sky-user")`，不要再拆一个同名的 `AddressBookClient`（否则启动报 `FeignClientSpecification` 冲突）。若必须拆多个接口，给每个加不同的 `contextId`。

当前契约落地：


| Client          | 服务名           | 方法（现状）                                      |
| --------------- | ------------- | ------------------------------------------- |
| `ProductClient` | `sky-product` | 按 id 查菜品/套餐；按 status 统计菜品/套餐数量             |
| `UserClient`    | `sky-user`    | 按 id 查地址；按时间统计用户数（已合并原 AddressBook）        |
| `PayClient`     | `sky-pay`     | `POST /pay` 发起支付（mock）                      |
| `OrderClient`   | `sky-trade`   | 支付成功回调；count / sumAmount / top10（报表用）      |


- [x] `sky-api` 模块可被其它服务依赖
- [x] 契约与阶段 2 清单对应（报表统计接口已补）

## 5. 每个业务服务的固定模板

迁任意服务都重复这套（对照笔记「拆一个服务」）：

1. 新建 Spring Boot 模块，引入 §2 依赖
2. 启动类：`@SpringBootApplication` + `@MapperScan("com.sky.mapper")`（有库才加）；调用方再加 `@EnableFeignClients(basePackages = "com.sky.skyapi")`
3. 拷贝本域 Controller / Service / Mapper / XML（**不要**依赖整个 `sky-server`）
4. 拷贝本服务需要的配置：`WebMvcConfiguration`（只注册本域拦截路径）、`GlobalExceptionHandler`；用到自动填充再拷 `AutoFill` + `AutoFillAspect`
5. `application.yml` + `application-local.yaml`（或 `dev`）：`profiles.active` 必须与环境文件名一致；`sky.datasource.*` 占位符要有值；`type-aliases-package: com.sky.entity`
6. 启动，Nacos 控制台出现实例；打开 `http://localhost:<端口>/doc.html`
7. 跨域 Mapper 全部改为注入 `sky-api` 的 Feign
8. 从 `sky-server` **注释或删除**已迁走的 Controller，避免你测错 8080

**包名约定：** 业务与公共类统一 `com.sky.*`（entity/dto 在 `sky-pojo`，工具在 `sky-common`）。不要用 IDE 重构把公共包改成 `com.sky.trade.*` / `com.sky.skyuser.*` 这种「模块名嵌套」——会搞垮全仓库。

yml 关键片段（各服务改 name / port / database）：

```yaml
server:
  port: 8082
spring:
  application:
    name: sky-product
  cloud:
    nacos:
      discovery:
        server-addr: 192.168.6.128:8848   # 换成你的
```

不要引入 `spring-cloud-starter-bootstrap`（配置中心是阶段 4）。

## 13. 常见坑


| 现象 | 排查 |
| ---- | ---- |
| Nacos 无实例 | `spring.application.name`、`server-addr`、9848 端口、防火墙 |
| Feign `404` | `path` / `@GetMapping` 与服务端不一致；`name` 与 `application.name` 不一致 |
| Feign `401` | 打到了需 JWT 的业务路径 → 改 `/inner/**` 并排除拦截 |
| `FeignClientSpecification` 冲突 | 同一 `name`（如 `sky-user`）挂了多个 `@FeignClient` → **合并接口**或加不同 `contextId` |
| `@EnableFeignClients` 扫不到 Client | 包名用 `com.sky.skyapi`，不是旧写法 `com.sky.api` |
| 加购价格/图片空 | 仍在用旧 Mapper；或 Inner 返回 `Result` 而 Feign 声明裸类型 |
| 下单地址空 | trade 还连着旧库 / Feign 没调通 |
| `${sky.datasource...}` 字面量 | `profiles.active` 与 `application-local/dev` 文件名不一致 |
| `type alias` 找不到 | `mybatis.type-aliases-package` 必须是 `com.sky.entity` |
| bean 名冲突 `*ServiceImpl` | 误依赖了 `sky-server` → **删依赖**，只拷本域代码 |
| 包变成 `com.sky.trade.dto` 等 | IDE 误重构公共模块 → 改回 `com.sky.*`（见 [问题.md](./问题.md)） |
| file 上传 URL 仍是 8080 | 配 `sky.file.upload-path` / `access-prefix` 指向 8086 |
| Knife4j Base64 / 文档挂 | 不要 `converters.add(0, JacksonConverter)`，见 [阶段1.md](./阶段1.md) |
| 两套接口都能调且数据不一致 | `sky-server` 与新服务同时开 → 停单体 |
