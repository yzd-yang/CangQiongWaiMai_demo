## 目标

把单体 `sky-server` **按域迁到独立服务**，注册 Nacos，跨域改 Feign。

```PowerShell
docker run -d \
--name nacos \
--env-file ./nacos/custom.env \
-p 8848:8848 \
-p 9848:9848 \
-p 9849:9849 \
--restart=always \
nacos/nacos-server:v2.1.0-slim
```

**本阶段不上网关**：用各服务自己的端口 + Knife4j 联调。JWT 先留在各服务拦截器（或 Feign 联调用 `/inner/`**）。

推荐顺序（由易到难，**迁完一个验收一个**）：

```text
BOM + 空骨架 + Nacos
  → sky-product
  → sky-user
  → sky-trade（Feign 调 product / user）
  → sky-file / sky-pay
  → sky-report
  → 归档 sky-server
```

## 4. `sky-api` 约定（对齐笔记 `hm-api`）

包名建议：`com.sky.api.client`。

**只放：**

- `@FeignClient(name = "sky-xxx", path = "...")` 接口
- 跨服务用的精简 DTO（不要把整个业务实体硬塞进来也行，初期可复用 `sky-pojo`）
- 可选：`DefaultFeignConfig`（日志级别，笔记同款）

**不要放：** Mapper、Service 实现、数据源、Controller。

Fallback 可阶段 5 再补。

启动类（**调用方**）：

```java
@EnableFeignClients(basePackages = "com.sky.api")
```

被调用方：提供与 Feign 路径一致的 Controller。建议单独一组 **内部接口**，避开 JWT：

```text
/inner/dish/{id}
/inner/setmeal/{id}
/inner/addressBook/{id}
```

在该服务 `WebMvcConfiguration` 里 `excludePathPatterns("/inner/**")`。

阶段 2 清单至少落地：


| Client                              | 服务名           | 最少方法                     |
| ----------------------------------- | ------------- | ------------------------ |
| `ProductClient`                     | `sky-product` | 按 id 查菜品、按 id 查套餐（名/图/价） |
| `AddressBookClient`（或 `UserClient`） | `sky-user`    | 按 id 查地址                 |
| `PayClient`                         | `sky-pay`     | 发起支付（可先 mock）            |
| `OrderClient`                       | `sky-trade`   | 更新支付状态；报表用的统计接口可后补       |


- [x] `sky-api` 模块可被其它服务依赖
- [x] 契约与阶段 2 清单对应

## 5. 每个业务服务的固定模板

迁任意服务都重复这套（对照笔记「拆一个服务」）：

1. 新建 Spring Boot 模块，引入 §2 依赖
2. 启动类：`@SpringBootApplication` + `@MapperScan("com.sky.mapper")`；调用方再加 `@EnableFeignClients`
3. 拷贝本域 Controller / Service / Mapper / XML
4. 拷贝本服务需要的配置：`WebMvcConfiguration`（只注册本域拦截路径）、`GlobalExceptionHandler`；用到自动填充再拷 `AutoFill` + `AutoFillAspect`
5. `application.yml`：`spring.application.name`、`server.port`、自己的数据源、Nacos `server-addr`、Knife4j/springdoc 的 `packages-to-scan`
6. 启动，Nacos 控制台出现实例；打开 `http://localhost:<端口>/doc.html`
7. 跨域 Mapper 全部改为注入 `sky-api` 的 Feign
8. 从 `sky-server` **注释或删除**已迁走的 Controller，避免你测错 8080

yml 关键片段（各服务改 name / port / database）：

```yaml
server:
  port: 8082
spring:
  application:
    name: sky-product
  cloud:
    nacos:
      discovery:
        server-addr: 192.168.6.128:8848   # 换成你的
```

不要引入 `spring-cloud-starter-bootstrap`（配置中心是阶段 4）。

**职责：** 分类、菜品、口味、套餐、店铺营业状态、Redis 缓存。

从 `sky-server` 拷贝：


| 类型           | 文件                                                                               |
| ------------ | -------------------------------------------------------------------------------- |
| 管理端          | `admin/CategoryController`、`DishController`、`SetmealController`、`ShopController` |
| 用户端          | `user/CategoryController`、`DishController`、`SetmealController`、`ShopController`  |

- `CategoryServiceImpl` 删分类时查菜品/套餐数量 → **同库**，保留 Mapper，不要 Feign

- 删图仍可用 `sky-common` 的 `FileUploadUtil`；等抽 `sky-file` 再改 HTTP
- 加 **内部接口** 供 trade Feign 查菜品/套餐

## 8. 抽 `sky-trade`（8083）— 本阶段核心

**职责：** 购物车、订单、催单、WebSocket、订单定时任务。

拷贝：


| 类型           | 文件                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------- |
| Controller   | `user/ShoppingCartController`、`user/OrderController`、`admin/OrderController`                      |
| Service      | `ShoppingCart*`、`Order*`                                                                          |
| Mapper + XML | `ShoppingCart`、`Order`、`OrderDetail`                                                              |
| 其它           | `webSocket/WebSocketServer`、`config/WebSocketConfiguration`、`task/OrderTask`、`task/WebSocketTask` |


**必须改成 Feign（禁止再注入外域 Mapper）：**


| 现有代码                                                       | 改为                  |
| ---------------------------------------------------------- | ------------------- |
| `ShoppingCartServiceImpl` → `DishMapper` / `SetmealMapper` | `ProductClient`     |
| `OrderServiceImpl` → `AddressBookMapper`                   | `AddressBookClient` |


下单顺序保持：

1. Feign 查地址
2. 读 **本库** 购物车；空则失败
3. 写本库 `orders` + `order_detail`
4. 清空本库购物车
5. WebSocket 仍在本服务

支付：本阶段可继续留在 `OrderServiceImpl.mockPayment`；抽 `sky-pay` 时再 Feign。跨库事务先本地 / 最终一致，不上 Seata。

用户 ID：拦截器能取到就用 `BaseContext`；Feign 联调卡 JWT 时可用 `/inner/**` 或临时写死（笔记允许，阶段 4 再统一网关传头）。

验收：

- [ ] Nacos 有 `sky-trade`
- [ ] 加购走 Feign 查商品，trade **未**配置 product 数据源
- [ ] 下单走 Feign 查地址，trade **未**配置 user 数据源
- [ ] Knife4j `8083` 跑通加购 → 下单（商品/用户服务同时开着）

## 13. 常见坑


| 现象                   | 排查                                                            |
| -------------------- | ------------------------------------------------------------- |
| Nacos 无实例            | `spring.application.name`、`server-addr`、9848 端口、防火墙           |
| Feign `404`          | `path` / `@GetMapping` 与服务端不一致；name 与 `application.name` 不一致  |
| Feign `401`          | 打到了需 JWT 的业务路径 → 改 `/inner/**` 并排除拦截                          |
| 加购价格/图片空             | 仍在用旧 Mapper 或 Feign DTO 字段没映射                                 |
| 下单地址空                | trade 还连着旧库 / Feign 没调通                                       |
| Knife4j Base64 / 文档挂 | 不要 `converters.add(0, JacksonConverter)`，见 [阶段1.md](./阶段1.md) |
| 循环依赖                 | 尽量拆 Bean；`allow-circular-references` 能不用则不用                   |
| 两套接口都能调且数据不一致        | `sky-server` 与新服务同时开且连不同库 → 停掉已迁域的单体 Controller               |
