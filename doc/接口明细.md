# 苍穹外卖 — 接口明细

> Base URL：`http://localhost:8080`  
> 在线文档：`http://localhost:8080/doc.html`（Knife4j）  
> 统一响应：`Result<T>` → `{ "code": 1|0, "msg": "...", "data": ... }`（`code=1` 成功）

## 鉴权说明

| 端 | Header 名称 | 说明 |
| -- | ----------- | ---- |
| 管理端 | `token` | 员工登录后返回的 JWT |
| 用户端 | `authentication` | 微信登录后返回的 JWT |

**无需 Token：**

- `POST /admin/employee/login`
- `POST /user/user/login`
- `GET /user/shop/status`（配置中放行的是 `/user/shop/login`，实际接口为 status，联调时以拦截器为准）

其余 `/admin/**`、`/user/**` 均需携带对应 Token。

# 一、管理端接口（`/admin`）

## 1. 员工管理 `/admin/employee`

### 1.1 员工登录

| 项 | 内容 |
| -- | ---- |
| 方法 / 路径 | `POST /admin/employee/login` |
| 鉴权 | 否 |
| 说明 | 员工登录，返回 JWT |

**请求体 `EmployeeLoginDTO`**

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

**响应 `data`：`EmployeeLoginVO`**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | long | 员工 ID |
| userName | string | 用户名 |
| name | string | 姓名 |
| token | string | JWT，后续请求放 Header `token` |

---

### 1.2 员工退出

| 项 | 内容 |
| -- | ---- |
| 方法 / 路径 | `POST /admin/employee/logout` |
| 鉴权 | 是 |

---

| -- | ---- |
| 方法 / 路径 | `POST /admin/employee` |
| 鉴权 | 是 |

**请求体 `EmployeeDTO`**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
