# 苍穹外卖（CangQiongWaiMai）项目文档

## 1. 项目概述

苍穹外卖是一套面向餐饮外卖业务的全栈 Demo 项目，后端基于 **Spring Boot** 多模块 Maven 工程，提供：

- **管理端（B 端）**：员工登录、分类/菜品/套餐管理、店铺营业状态、订单处理、工作台与数据报表
- **用户端（C 端）**：微信登录、浏览菜品/套餐、购物车、地址簿、下单支付、催单等

项目根 Artifact：`com.sky:sky-take-out:1.0-SNAPSHOT`  
默认服务端口：`8080`  
数据库名：`sky_take_out`

## 3. 工程结构

```
CangQiongWaiMai_demo/
├── pom.xml                 # 父工程，统一依赖版本
├── sky.sql                 # 数据库建库建表及初始数据
├── frontend/               # 前端相关说明
├── sky-common/             # 公共模块：常量、异常、工具、统一返回、配置属性
├── sky-pojo/               # 实体、DTO、VO
└── sky-server/             # 启动与业务模块：Controller / Service / Mapper / 配置
```

### 3.1 sky-common

公共能力与横切关注点：

- `result`：统一响应 `Result`、`PageResult`
- `exception`：业务异常体系（登录失败、订单异常等）
- `constant` / `enumeration`：状态常量、消息常量、操作类型
- `context.BaseContext`：基于 ThreadLocal 传递当前登录用户 ID
- `utils`：JWT、HttpClient、OSS、微信支付、文件上传等
- `properties`：JWT、微信、OSS 等配置属性类

### 3.2 sky-pojo

数据模型分层：

- `entity`：与数据库表对应的实体
- `dto`：接口入参对象
- `vo`：接口出参 / 报表视图对象

### 3.3 sky-server

业务与启动入口：

- 启动类：`com.sky.SkyApplication`
- `controller.admin`：管理端接口（`/admin/**`）
- `controller.user`：用户端接口（`/user/**`）
- `service` / `service.impl`：业务逻辑
- `mapper` + `resources/mapper/*.xml`：数据访问
- `config`：WebMvc、Redis、WebSocket 等配置
- `interceptor`：JWT 拦截器
- `aspect`：公共字段自动填充切面
- `task`：订单超时等定时任务
- `webSocket`：来单提醒等实时推送

依赖关系：

```
sky-server → sky-common
sky-server → sky-pojo
```

## 5. 核心业务功能

### 5.1 管理端

| 模块 | 路径前缀 | 主要能力 |
| ---- | -------- | -------- |
| 员工管理 | `/admin/employee` | 登录/登出、增删改查、启用禁用、分页 |
| 分类管理 | `/admin/category` | 菜品/套餐分类 CRUD、启停 |
| 菜品管理 | `/admin/dish` | 菜品及口味维护、起售停售、缓存清理 |
| 套餐管理 | `/admin/setmeal` | 套餐及菜品组合、起售停售、缓存驱逐 |
| 订单管理 | `/admin/order` | 条件查询、接单/拒单/取消、派送、完成、状态统计 |
| 店铺状态 | `/admin/shop` | 营业/打烊（Redis 存储） |
| 通用上传 | `/admin/common` | 文件上传 |
| 工作台 | `/admin/workspace` | 今日营业数据、订单/菜品/套餐概览 |
| 数据统计 | `/admin/report` | 营业额、用户、订单、销量 Top10、Excel 导出 |

### 5.2 用户端

| 模块 | 路径前缀 | 主要能力 |
| ---- | -------- | -------- |
| 用户 | `/user/user` | 微信登录 |
| 分类 | `/user/category` | 查询启用分类 |
| 菜品 | `/user/dish` | 按分类查询菜品（Redis 缓存） |
| 套餐 | `/user/setmeal` | 套餐列表（Spring Cache）、套餐内菜品 |
| 购物车 | `/user/shoppingCart` | 加购、减购、列表、清空 |
| 地址簿 | `/user/addressBook` | 地址 CRUD、默认地址 |
| 订单 | `/user/order` | 下单、支付、历史订单、取消、再来一单、催单 |
| 店铺 | `/user/shop` | 查询营业状态 |

### 5.3 订单状态流转

订单状态定义（`Orders` 实体）：

| 状态值 | 含义 |
| ------ | ---- |
| 1 | 待付款 |
| 2 | 待接单 |
| 3 | 已接单 |
| 4 | 派送中 |
| 5 | 已完成 |
| 6 | 已取消 |
| 7 | 退款 |

典型流程：

```
用户下单 → 待付款 → 支付成功 → 待接单
                → 商家接单 → 已接单 → 派送中 → 已完成
                → 超时未支付 / 取消 / 拒单 → 已取消
```

支付状态：`0` 未支付 / `1` 已支付 / `2` 退款。

## 6. 数据库设计

数据库脚本：项目根目录 `sky.sql`。

| 表名 | 说明 |
| ---- | ---- |
| `employee` | 商家员工 |
| `category` | 分类（1 菜品分类 / 2 套餐分类） |
| `dish` | 菜品 |
| `dish_flavor` | 菜品口味 |
| `setmeal` | 套餐 |
| `setmeal_dish` | 套餐与菜品关联 |
| `user` | C 端用户（微信 openid） |
| `address_book` | 收货地址 |
| `shopping_cart` | 购物车 |
| `orders` | 订单主表 |
| `order_detail` | 订单明细 |

核心关系简述：

- 分类 1:N 菜品 / 套餐
- 菜品 1:N 口味
- 套餐 N:N 菜品（经 `setmeal_dish`）
- 用户 1:N 地址 / 购物车 / 订单
- 订单 1:N 订单明细

默认管理员账号（脚本初始数据）：

- 用户名：`admin`
- 密码：`123456`（以实际库中存储为准，生产环境务必修改）

## 7. 关键技术点

### 7.1 公共字段自动填充（AOP）

- 注解：`@AutoFill(OperationType.INSERT / UPDATE)`
- 切面：`AutoFillAspect`
- 作用：自动填充 `createTime`、`updateTime`、`createUser`、`updateUser`

### 7.2 Redis 缓存

- **店铺营业状态**：Key `SHOP_STATUS`
- **菜品列表缓存**：Key 形如 `dish_{categoryId}`，管理端变更菜品时清理
- **套餐列表缓存**：`@Cacheable` / `@CacheEvict`，缓存名 `setmealCache`

### 7.3 WebSocket 来单提醒

- 端点：`/ws/{sid}`
- 服务端类：`WebSocketServer`
- 用途：用户下单/催单等场景向管理端推送消息

### 7.4 定时任务（`OrderTask`）

| 任务 | Cron | 说明 |
| ---- | ---- | ---- |
| 支付超时处理 | 每分钟 | 超过约 15 分钟未支付的订单自动取消 |
| 派送中订单处理 | 每天 1 点 | 将符合条件的派送中订单置为已完成 |

### 7.5 全局异常与统一返回

- `GlobalExceptionHandler` 捕获业务异常
- 接口统一返回 `Result<T>`，分页返回 `PageResult`

### 7.6 报表导出

管理端 `/admin/report/export` 使用 POI 导出运营数据 Excel。

## 8. 配置说明

主配置：`sky-server/src/main/resources/application.yml`  
开发环境：`application-dev.yml`（`spring.profiles.active: dev`）

主要配置项：

```yaml
server.port: 8080

sky.datasource:   # MySQL 连接
sky.redis:        # Redis 连接
sky.jwt:          # 管理端/用户端 JWT 密钥与过期时间
sky.wechat:       # 微信小程序 appid / secret
```

开发环境默认示例（请按本机环境修改）：

| 项 | 默认值 |
| -- | ------ |
| MySQL | `localhost:3306/sky_take_out`，用户 `root` / `123456` |
| Redis | `localhost:6379`，database `0` |
| 端口 | `8080` |

微信、OSS、支付相关密钥请通过配置文件或环境变量注入，**不要提交真实生产密钥到仓库**。

## 9. 本地运行指南

### 9.1 环境要求

- JDK 8+
- Maven 3.6+
- MySQL 5.7+ / 8.x
- Redis 5+

### 9.2 初始化数据库

```bash
mysql -u root -p < sky.sql
```

或在客户端中执行 `sky.sql`。

### 9.3 修改配置

编辑 `sky-server/src/main/resources/application-dev.yml`，调整数据库、Redis、微信等配置。

### 9.4 启动后端

在项目根目录执行：

```bash
mvn clean install
mvn -pl sky-server spring-boot:run
```

或在 IDE 中直接运行 `com.sky.SkyApplication`。

### 9.5 验证

- 健康启动日志中出现 `server started`
- 打开接口文档：`http://localhost:8080/doc.html`
- 管理端登录接口：`POST /admin/employee/login`

## 12. 注意事项

1. 本仓库为学习/演示向外卖系统后端，部分第三方能力（微信登录、支付、OSS）需自行配置有效凭证后才能完整联调。
2. `application-dev.yml` 中的数据库密码、微信密钥等仅适用于本地开发，上线前请更换并做好密钥管理。
3. 菜品/套餐变更后需正确清理 Redis / Cache，否则用户端可能读到旧数据。
4. WebSocket 与定时任务依赖服务进程常驻运行。
5. 前端资源说明见 `frontend/` 目录；数据库表结构亦可参考根目录已有设计说明与 `sky.sql`。
